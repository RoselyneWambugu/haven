Echo — Wireframes: Admin dashboard

Draft v0.1 · low-fidelity · follows PRD §6.11 (admin), §6.7 (moderation) and §6.9 (privacy). Desktop web, MFA required. Every figure is a placeholder (—). Pink markers match the numbered notes under each pair. Not committed.

Principles for every admin screen

  • Public view by default. Staff see pen names; real identity sits behind a logged, approved break-glass request.
  • Content only inside a case. Message text appears only in a case snapshot, blurred until revealed, with a daily reveal counter to protect reviewers’ wellbeing.
  • Everything is logged. Views, sanctions, reveals, exports and permission changes go to an append-only audit log.
  • Role-based. The role badge at the top right of each window shows who is signed in; each role sees only its own modules.
