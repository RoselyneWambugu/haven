Echo — Wireframes: Registration, profile setup, settings and account

Draft v0.1 · low-fidelity · follows screen-flows.md §2 and §8, PRD §6.1, §6.2 and §7. Welcome and consents are in the first wireframe set (screen 1). Pink markers match the numbered notes beside each group. Placeholders are marked ___ . Not committed.

Principles

  • Private by default, said plainly. Every place that asks for real details says that others never see them.
  • Data minimisation: under-18 sign-ups are deleted immediately; ID photos are deleted after checking; nothing is asked that isn’t used.
  • No passwords: sign-in is by phone and one-time code, bound to the device (D35).
  • Safety is never switched off: urgent help stays in the top bar and safety notices can’t be disabled.

Decisions and gaps

  • D33: when exactly is ID verification required, and with which provider? Drawn as escalation-only.
  • D34: deletion holding period (14 days?), what must be retained, and for how long (counsel).
  • D35: sign-in by phone and one-time code only, device-bound, no passwords. Confirm, including how to recover access if a phone is lost.
  • D36: how often can a pen name be changed, and are old names kept for moderation?
  • Email: optional here. Is it needed at all, for example receipts and account recovery?
  • Languages: is the list English, Kiswahili, Sheng plus local languages? Matching quality depends on it.
  • Not yet drawn: therapist directory list, booking confirmation, in-call screens for members (voice and video), login for returning users.
